## How these files work

- JavaScript examples run one file at a time with Node.js. Each file includes its own variables.
- Day 19 opens in your browser. Keep its HTML and CSS files together.
- Day 16 uses Playwright and has its own setup instructions.
- Days 17 and 18 include commands to enter in the terminal, one line at a time.

You can read and copy from this public repository without a GitHub account.
You do not need to clone, fork, or push anything to use an example.
Save your changes in your own practice folder.

Some recordings show earlier course numbers or filenames, such as
`day5-variables.js`, `day6-operators.js`, `day7-loops-functions.js`, and
`day8-arrays-objects.js`. Here, the folders follow the current Day 16–23 schedule.
The combined JavaScript demonstrations are split into small, independent files.
Use the filenames and commands written in this repository.
